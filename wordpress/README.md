# design casa 宇都宮 ／ 株式会社エスホーム — WordPressテーマ

FTPで `wp-content/themes/` に置いて有効化するだけで、施工例67件・建築家13名・仕様8項目まで揃うWordPressテーマです。

---

## 1. FTPでのアップロード手順

### 置く場所

```
（WordPressのルート）
└ wp-content/
  └ themes/
    └ designcasa-shome/   ← このフォルダごとアップロード
```

このリポジトリの `wordpress/wp-content/themes/designcasa-shome/` を、
**フォルダごと** サーバーの同じ階層にアップロードしてください。

### FTPクライアントの設定

| 項目 | 設定 |
|---|---|
| 転送モード | **バイナリ**（または自動判別）。アスキー固定にすると画像が壊れます |
| 文字コード | **UTF-8** |
| 上書き | 「常に上書き」 |

> 画像が659点あります。回線によっては15〜30分かかります。
> 途中で切れた場合は、差分だけ再アップロードすれば大丈夫です。

### アップロード後

1. WordPress管理画面 →「外観 > テーマ」→ **design casa 宇都宮 / S HOME** を **有効化**
2. 画面上部に「初期データがまだ取り込まれていません」と出るので、**「取り込み画面をひらく」** をクリック
3. **「取り込みを開始する」** を押して、進捗バーが100%になるまで待つ（数分。画面は開いたままに）
4. 「設定 > パーマリンク設定」を開いて **「変更を保存」を1回押す**（URLの再構築。これを忘れると施工例ページが404になります）

これで公開状態になります。

## 2. 有効化したときに自動で行われること

- パーマリンクを「投稿名」に設定（未設定の場合のみ）
- 固定ページを作成：デザインカーサとは / 家づくりの流れ / 施工会社紹介 / 資料請求・お問い合わせ / プライバシーポリシー
- ヘッダーメニュー・フッターメニューを作成して割り当て
- カスタム投稿タイプを登録：施工例・建築家・家の仕様・お問い合わせ

「初期データの取り込み」で行われること：

- 施工例 67件（写真659点・1枚ずつコメント付き）をメディアライブラリへ取り込み
- 建築家 13名、家の仕様 8項目を登録
- 施工例に「平屋」「中庭」「ガレージ」などの特徴タグを付与

すでに登録済みのものは**上書きされません**。安心して再実行できます。

### SEOのために入れてあるもの

- `<title>` / `<meta name="description">` をページ種別ごとに自動生成（1ページずつ手動で上書きも可）
- OGP・Twitterカード
- canonical・robots
- **構造化データ（JSON-LD）**
  - `HomeAndConstructionBusiness`（社名・住所・電話・営業時間・対応エリア16市町）＝ローカルSEOの土台
  - `BreadcrumbList`（パンくず）
  - `FAQPage`（トップ・流れ・問い合わせページのQ&A）
  - `CreativeWork`（施工例）
- パンくずリストの表示
- 見出し階層（h1は各ページ1つ）
- 画像の `alt` を「物件名＋所在地＋注文住宅 施工例」で自動生成
- 内部リンク（施工例↔建築家↔仕様↔問い合わせ）
- モバイル下部の固定CTA（電話・資料請求）

> **SEOプラグインを入れた場合**：Yoast SEO / Rank Math / SEO SIMPLE PACK などを有効化すると、
> テーマ側のタイトル・メタ出力は自動で止まります。二重出力の心配はありません。

## 5. 公開前に必ず設定してください

1. **問い合わせの通知先メール**
   「外観 > カスタマイズ > 会社情報（design casa）」→「お問い合わせの通知先メールアドレス」
   空欄の場合は「設定 > 一般」の管理者メールに届きます。

2. **メールが届くかのテスト**
   自分宛にフォームを1回送信して、通知メールと自動返信メールの両方が届くか確認してください。
   届かない場合は **WP Mail SMTP** などのプラグインでSMTP送信に切り替えてください（レンタルサーバーの `wp_mail` は迷惑メール判定されがちです）。

3. **Googleマップ**
   「外観 > カスタマイズ > 会社情報」→「Googleマップの埋め込みURL」
   未設定でも住所検索の地図が出ますが、正式な埋め込みURLを入れるときれいに出ます。

4. **会社情報の確認**
   同じカスタマイズ画面で、以下が正しいか社内の正式表記と突き合わせてください。

   | 項目 | 現在の値 | 出典 |

   | フリーダイヤル | 0120-934-606 | shome.co.jp |
   | TEL / FAX | 028-613-6606 / 028-613-6616 | **要確認** |
   | 設立 | 昭和48年10月15日 | **要確認** |
   | 代表者 | 西村 寛 | **要確認**（サイトには姓のみ記載） |

   > **要確認**と書いた項目は、公開サイトに明記がなく仮の値を入れています。**公開前に必ず差し替えてください。**

5. **サイトのタイトル・キャッチフレーズ**
   「設定 > 一般」で設定してください。

6. **施工例の数値データ**

   design casa 公式サイトの掲載時点の一覧です。増減があるため公開前に照合してください。
   氏名・事務所名のみの9名には、写真とプロフィールがありません。

## 6. 掲載データについての注意

- **施工例の写真は design casa（カーサプロジェクト）の全国の施工実例**です。エスホームの自社施工物件ではありません。
  誤認を避けるため、一覧・詳細・フッターにその旨を明記しています。表記方法はブランド側の規定に合わせてください。
- **仕様ページには価格を一切載せていません。**
  `casa_HP_data/仕様` フォルダにある価格表・掛率・発注書は社外秘の商流資料と判断し、
  公開してよい**製品名・メーカー名のみ**を掲載しています。
- **仕様ページの建材写真は、利用条件の表記に従って選んでいます。**

  | 素材 | フォルダの表記 | 扱い |
  |---|---|---|
  | KUUMA サウナ | 商品イメージ写真（**HP・SNS利用可**）／施工事例（**HP・SNS利用可**） | 掲載 |
  | PLY キッチン・洗面（田中工藝） | `00_製品写真` | 掲載 |
  | PLY キッチン・洗面（田中工藝） | `01_施工事例`（**SNS利用不可**） | **掲載していません** |
  | その他の建材 | 利用条件の表記なし | 掲載せず、design casa 施工実例の写真で代替 |

  新たにメーカー写真を追加する際は、各社の利用条件をご確認ください。

## 8. 施工例の並び順について

Boxのフォルダ名の頭についている番号（01〜79）を `menu_order` に入れ、
**番号の大きいものが先に表示**されます（＝新しい施工例が上）。

管理画面「施工例」の **整理番号** を書き換えると、並び順にも自動反映されます。

## 10. WordPressを使わずに見た目を確認する（preview/）

リポジトリ直下の `preview/` は、**WordPressを入れずにテーマの見た目を確認するためだけ**の仕組みです。
WordPressの関数を最小限だけ真似た「仮の土台」の上で、`designcasa-shome/` の実テンプレートをそのまま描画します。

```bash
php -S 127.0.0.1:8787 -t . preview/router.php
```

ブラウザで `http://localhost:8787/` を開いてください。

**本番サーバーには `preview/` をアップロードしないでください。**（不要です。削除して問題ありません）
