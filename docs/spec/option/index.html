オプション

オプション ─ サウナ・オリジナル表札

全国ネットワークだからこそ用意できる、少し特別な選択肢もあります。

KUUMA サウナハウス

庭に置く独立型のサウナハウスです。本体は工場でつくられ、現地に設置します。

建物本体とは別に計画できるため、外構の一部として、あるいは将来の追加として検討できます。宇都宮市の郊外で、敷地に余裕のある方からのご相談が増えています。

casa オリジナル表札

黒皮鉄または真鍮を使った、design casa オリジナルの表札です。長方形・正方形の形状と、複数の書体から選べます。

毎日目にする場所であり、来客が最初に見る場所でもあります。既製品にはない素材感は、経年で表情が変わっていきます。

その他のご相談

ここに挙げたもの以外にも、ご要望に応じて検討します。「できるかどうか分からない」ものこそ、まずはご相談ください。設計の初期段階であれば、実現できる可能性が高くなります。
