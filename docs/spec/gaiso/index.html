外装

外装・屋根 ─ 20年後の手間まで含めて選ぶ

design casa の外観を支える外壁材。汚れにくさと補修のしやすさを、意匠と同じ重さで検討します。

外壁は「かっこよさ」だけで選べない

外壁は、家のなかでもっとも紫外線と雨風にさらされる部分です。竣工写真が美しくても、10年後に汚れが流れ落ちた跡が残るようでは意味がありません。

当社では、素材ごとの経年変化の出方をご説明したうえで選んでいただいています。

塗り壁（Sto／セラディール）

継ぎ目のない一枚の面をつくれるのが塗り壁の魅力です。サイディングのような目地がないため、シャープな箱型の外観に向いています。

Sto は外断熱と一体で施工できるシステムで、断熱性能を高めながら意匠をつくれます。表面に汚れが付きにくい仕上げを選ぶことも可能です。

スイス漆喰 カルクウォール

自然素材の漆喰です。強アルカリ性でカビや藻が生えにくく、時間とともに硬く強くなっていく性質があります。工業製品にはない、面のゆらぎが出るのが特徴です。

ガルバリウム鋼板

メンテナンス性を優先するならガルバリウム鋼板。軽いため耐震の面でも有利で、design casa の施工例では黒や濃いグレーの縦張りが多く使われています。

木の外壁

木は必ず経年変化します。この変化を「劣化」と捉えるか「味」と捉えるかで、選ぶかどうかが決まります。玄関まわりなど、部分的に使うことで手入れの負担を抑える方法もあります。

宇都宮市は積雪が多い地域ではありませんが、冬の凍結と夏の高温による伸縮は考慮が必要です。
