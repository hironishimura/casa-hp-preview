小倉 大助 おぐら だいすけ

小倉建築計画工房（東京都）

経歴

東京都出身。2008年、日本大学生産工学部建築工学科を卒業。
アトリエ系設計事務所勤務を経て、2018年に小倉建築計画工房を設立。
住宅や小規模建築の設計を中心に活動。

難しい条件こそ、建築における最高のスパイスになる。

住まいづくりは、ご要望・敷地条件・ご予算・ライフスタイルなど、さまざまな条件を紐解きながら行うものです。それらが難しい条件であることは、建築するうえでの最高のスパイスになると私は考えています。

対話を重ねながら、そこにしかない唯一無二の住まいづくりをお手伝いさせていただきます。

狭い、変形している、隣家が近い。宇都宮市の市街地でもよくある条件は、裏を返せばその家だけの形を生む理由になります。

この建築家と、宇都宮で家を建てる

design casa では、建築家と直接3回打ち合わせをしながらプランをつくります。 施工と保証は宇都宮市の工務店・株式会社エスホームが担当し、 耐震等級3・断熱等級6の標準仕様で仕上げます。
